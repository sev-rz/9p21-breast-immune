# scripts

Analysis code, run by the Snakemake rules in `workflow/Snakefile` (see the table in the main README).

- Run from the project folder (`pixi run python scripts/x01_brca_core.py`), with paths
  relative to the project folder.
- Random seeds are fixed in the scripts.
- `audit.py`, `pilot.py` are early exploration, kept for the record.
